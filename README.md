# DDL Marker

一个本地运行的DDL提醒工具，可以帮助你管理和跟踪各种截止日期任务。

## 功能特性

1. **智能日期识别**：自动识别多种格式的日期时间输入（如"2024-12-31 23:59"、"明天 14:30"等）
2. **自动排序**：按截止日期从近到远排序任务
3. **灵活提醒**：可自定义提醒时间，支持分钟、小时和天级别设置，可以为每个任务单独设置提醒时间，默认提前30分钟、1小时和1天提醒
4. **本地存储**：重启电脑后数据依然保留
5. **标签管理**：支持自定义标签分类，快速筛选任务
6. **完成标记**：手动勾掉已完成的任务，不再提醒
7. **桌面浮窗**：始终保持在窗口顶层，方便随时查看
8. **批量导入**：支持按特定格式批量导入任务
9. **开机自启动**：可以设置程序在开机时自动运行，确保不会错过任何提醒

## 使用方法

### 启动应用

在命令行中运行：
```
python ddlmarker.py
```

### 添加任务
1. 输入任务名称
2. 输入截止日期时间（支持多种格式）
3. 选择标签
4. 点击"添加任务"按钮

### 批量导入任务
1. 点击"批量导入"按钮
2. 按照提示格式输入多个任务（每行一个）
3. 点击"导入"按钮

### 管理标签
1. 点击"管理标签"按钮
2. 可以添加或删除标签

### 自定义提醒时间
1. **全局提醒设置**：
   - 点击"提醒设置"按钮
   - 在自定义提醒区域，输入提前量并选择时间单位（分钟/小时/天）
   - 点击"添加"按钮保存全局提醒设置
   - 也可以使用快捷按钮添加常用提醒时间
   - 可以删除不需要的提醒设置

2. **任务独立提醒设置**：
   - 在添加或编辑任务时，勾选"使用自定义提醒设置"选项
   - 输入提前量并选择时间单位（分钟/小时/天）
   - 点击"添加"按钮为该任务添加独立提醒时间
   - 默认提醒设置为提前30分钟、1小时和1天

## 数据存储

所有任务和设置数据保存在程序目录下的`ddl_data.json`文件中。

## 注意事项

- 程序需要保持运行才能接收提醒
- 关闭程序时会自动保存所有数据
- 任务完成后请记得标记为已完成，避免不必要的提醒
